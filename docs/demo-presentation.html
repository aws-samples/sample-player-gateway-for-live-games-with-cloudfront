🔐 JA4 TLS Fingerprint Analysis

JA4 is a 36-character hash derived from the TLS Client Hello handshake. Each game client SDK produces a consistent, unique fingerprint based on its TLS configuration (cipher suites, extensions, supported versions).

How It Works

  • Game Client SDK → Consistent JA4 fingerprint (e.g., t13d1516h2_8daaf6152771_e5627efa2ab1)
  • Python bot → Different fingerprint (e.g., t13d1715h2_5b57614c22b0_3d5424432f57)
  • Go bot → Another fingerprint (e.g., t13d1517h2_a56f5b993250_06cda9e17597)

Even if attackers rotate IPs, their TLS fingerprint remains constant — making botnets detectable across distributed infrastructure.

Gaming Use Case: During a reconnection storm, all legitimate game clients share the same JA4 fingerprint (game client SDK). The WAF allows high throughput for this known-good fingerprint while blocking unknown fingerprints (bots, scrapers) at a much lower threshold. This is the key to preventing false-positive DDoS blocks during mass reconnection events.
